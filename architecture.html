System Overview

User Flows
1

Channel Message → Status Update

A user posts in Slack mentioning their work location. The bot silently detects and records it.

Message hits pre-filter regex (wfh, office, sick…)
Claude Haiku classifies intent + extracts date (64 tokens max)
Date validated — past dates and >1 month rejected
Status written to overrides table
Thread reply + emoji reaction sent
If today → Orchestrator fires (negotiation DMs)
If future → notifyDependents fires (DMs to score ≥ 7)
2

DM Chatbot → Schedule Query / Update

A user messages the bot directly to check schedules or update their own status conversationally.

DM received by chatbot listener
Claude Opus runs ReAct loop with 4 tools
Tools: find_user, get_user_schedule, get_team_schedule, set_my_status
Conversation history kept per user (in-memory)
If status updated today → Orchestrator fires
If future date → notifyDependents fires
3

App Home → Override Modal

User opens the HybridSync tab in Slack and manually edits their week via a dropdown modal.

User clicks "Edit Schedule" button
Placeholder modal opened instantly (3s trigger_id deadline)
Real schedule loaded from DB, modal updated
User sets Mon–Fri statuses and saves
Each day written to overrides table
notifyDependents fires for each changed day
App Home refreshed + confirmation DM sent
4

Orchestrator → Negotiation DM

When a status changes today, the AI checks collaborators and lets them decide if they want to adjust.

Orchestrator receives triggering user + new status
get_dependency_graph tool → fetches collaborators
Claude reasons about who is impacted (score ≥ 7)
send_negotiation_dm → Block Kit DM with two buttons
Collaborator clicks "Switch WFH" or "Stay Office"
Their choice written to DB, App Home refreshed
DM buttons collapse into confirmation text
5

Weekly Batch → Dependency Rebuild

Every Sunday at 2AM (or on-demand), the dependency graph is recalculated from real Slack data.

fetchSlackInteractions reads all public channels (30 days)
Counts @mentions, thread replies, emoji reactions per pair
Claude Opus scores each pair 1–10 based on interaction counts
Entire dependencies table wiped
Fresh scores written for all pairs
6

React Dashboard → Admin View

HR and managers log in to a web dashboard to see the full team picture and manage settings.

Login with role (HR sees all, Manager sees own team)
JWT token stored, used for all API calls
GodView: full team schedule grid + dependency graph viz
SquadView: manager's team only + anchor day editor
"Recalculate Dependencies" triggers batch rebuild on demand
Key Components
📢

stream.js

listeners/stream.js

Listens to all public channel messages. Uses a regex pre-filter before hitting AI to keep costs low. Calls Claude Haiku (64 tokens) to classify intent and extract date.

Slack event Haiku Overrides
🤖

chatbot.js (AI)

ai/chatbot.js

Claude Opus agent with 4 tools and per-user conversation memory. Handles natural language schedule queries and updates via DM.

Opus 4.7 DM 4 tools
🧠

orchestrator.js

ai/orchestrator.js

Claude Opus ReAct loop. Fires on today's status changes only. Analyses dependency graph and sends negotiation DMs to high-score collaborators. Never silently modifies others' schedules.

Opus 4.7 ReAct loop 2 tools
⚙️

batch.js

ai/batch.js

Weekly cron (Sun 2AM) that reads 30-day Slack interaction history across all channels, feeds counts to Claude, and rewrites the full dependency graph.

Cron Opus 4.7 Full rebuild
🔔

notifications.js

services/notifications.js

Shared service called by stream, chatbot, and override. DMs all collaborators with score ≥ 7 when someone's future status changes. Includes negotiation buttons.

Shared Block Kit score ≥ 7
🔗

slackStatus.js

services/slackStatus.js

Registered as a hook on every DB write. Syncs today's status to the user's native Slack profile using their personal OAuth token (users.profile:write scope).

Hook OAuth Profile sync
⚡

provider.js

ai/provider.js

AI abstraction layer. Auto-detects Anthropic or Groq from env vars. Exposes two functions — runAgentLoop (with tools) and complete (one-shot). Both providers share the same interface.

Anthropic Groq fallback Prompt cache
🗄️

db/index.js

db/index.js

Entire Supabase data layer. Two-layer schedule resolution (overrides win over weekly defaults). Fires onStatusChange hook after every write. Auto-seeds on first run.

Supabase 4 tables Hook system
🌐

server.js

server.js

Express REST API on port 3001. JWT-based auth with HR and Manager roles. Serves schedule, graph, and team data to the React dashboard. Handles Slack OAuth callback.

REST :3001 JWT OAuth

AI Models

Status Classifier

claude-haiku-4-5-20251001

Used in stream.js to classify every channel message. Extremely cheap and fast — 64 token output max. Only fires if message passes regex pre-filter.

Prompt caching on system prompt
Returns JSON: isUpdate + status + dateHint
Handles negations ("not wfh" → Office)
Non-English messages supported

Orchestrator + Chatbot

claude-opus-4-7

Used for complex reasoning tasks — orchestrator ReAct loop and DM chatbot. Supports adaptive thinking mode for harder problems.

Adaptive thinking enabled
Prompt caching on system prompt
Max 8 iterations per ReAct loop
4096 token output

Dependency Scorer

claude-opus-4-7 (complete)

Used by weekly batch job. Single one-shot call with no tool loop — receives interaction counts, returns a JSON array of scored pairs.

No agent loop — single completion call
2048 token output
Prompt caching on system prompt
Scores 1–10 per directional pair

Groq Fallback

llama-3.3-70b-versatile

If no Anthropic key is set, provider.js automatically switches to Groq via the OpenAI-compatible API. Tool schemas are converted automatically.

OpenAI-compatible API
Auto tool schema conversion
Same runAgentLoop interface
Zero code changes needed
